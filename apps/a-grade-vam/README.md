# a-grade-vam

Connect IQ **data field** for Garmin Edge 830/840: current grade (%) + VAM (vertical ascent speed, m/h), computed from barometric altitude and distance.

This is **Option A** of the project spec — see [`GARMIN_MTB_SPEC.md`](../../GARMIN_MTB_SPEC.md), section 4.
