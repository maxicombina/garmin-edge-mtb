# b-grade-vam

Connect IQ **data field** for Garmin Edge 830/840: current grade (%) + VAM (vertical ascent speed, m/h), computed from barometric altitude and distance.

This is **Option B** of the project spec — see [`GARMIN_MTB_SPEC.md`](../../GARMIN_MTB_SPEC.md), section 4.

## Status

Spec complete ([`SPEC.md`](SPEC.md)). Implementation starts after Phase 0 (Option A, [`apps/a-activity-timer/`](../a-activity-timer/)) is done.
